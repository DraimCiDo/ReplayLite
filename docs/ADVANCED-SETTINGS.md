# Расширенные настройки

В текущих исходниках ReplayLite нажмите **шестерёнку справа вверху → Расширенные**. Вкладок нет. Дополнительные параметры собраны на одном экране с прокруткой. **Закруглённая стрелка слева** возвращает сначала в обычные настройки, затем на экран записи. Размер окна не меняется. Новый релиз автоматически не создаётся: опубликованная версия может ещё не содержать эти параметры.

Расширенная страница создаётся при первом открытии. Новых постоянных таймеров нет. Ползунок показывает значение в соседнем поле: можно перетаскивать мышью, использовать стрелки/Home/End или ввести число и нажать Enter. Запись настройки происходит после отпускания ползунка/клавиши или завершения ввода, а не на каждом движении мыши. Число ограничивается допустимым диапазоном.

## Захват

- FPS и битрейт доступны только в обычных настройках, без дублирования на расширенном экране.
- **Записывать курсор**: включено по умолчанию; действует и для Desktop Duplication, и для резервного Windows Graphics Capture.
- Видео записывается в исходном разрешении через H.264 NVENC. Изменение разрешения пока не предлагается: аппаратный фильтр масштабирования в закреплённой сборке не прошёл проверку на используемой видеокарте. Экспорт остаётся без перекодирования.

## Звук

Устройства компьютера и микрофона выбираются независимо. «Устройство по умолчанию» следует выбору Windows. Конкретное устройство сохраняется по идентификатору: смена системного устройства по умолчанию не переключает запись на другой источник. Если выбранное устройство отсутствует, выбор сохраняется, источник временно даёт тишину и повторно подключается при возвращении. Видео и доступный второй источник продолжают записываться.

Громкость каждого источника — **0–100%**. 0% даёт тишину, 100% оставляет исходную амплитуду; усиления выше 100% нет. Эти параметры меняют только записываемый звук, а не системную громкость Windows. При 100% дополнительный проход умножения PCM пропускается. При смешивании двух источников сохраняется существующий лимитер, поэтому это не обещание линейной громкости итогового микса при любой входной нагрузке.

Включённые источники определяются режимом в обычных настройках: «Компьютер и микрофон», «Только звук компьютера», «Без звука». Настройка микрофона не включает его вопреки выбранному режиму. Список устройств обновляется при открытии расширенных настроек, без постоянного опроса.

## Хранение

**Папка временного буфера** отделена от папки готовых MP4. Для стандартной папки поле показывает «По умолчанию», полный путь доступен в подсказке. Кнопка «Изменить» выбирает другую папку; длинный путь сокращается внутри скруглённого поля. В ней создаётся отдельная папка `buffer-*` для текущего сеанса. При остановке удаляется только эта папка сеанса; родительская папка и чужие файлы остаются. Настройки продолжают храниться в прежнем месте. Пользовательский путь абсолютный; после переноса Portable на другой диск его следует проверить.

**Минимум свободного места**: 128–10240 МБ. При включённой «Остановке при нехватке места» запись останавливается с ошибкой ниже выбранного порога. При выключенном переключателе остаётся обязательная защита 128 МБ. При запуске дополнительно проверяется запас для выбранной длины и битрейта буфера. Поэтому порог 128 МБ не означает, что для запуска достаточно ровно 128 МБ.

Проверяется накопитель буфера. Свободное место для экспорта на другой накопитель этим порогом не гарантируется. Ошибка экспорта сохраняет буфер для повторной попытки. Сохранённые MP4 автоматически не удаляются; при остановке записи несохранённый временный буфер очищается.

## Общие

- **Анимации интерфейса**: по умолчанию включены. Управляют короткими переходами кнопок, статуса и шкалы буфера основного окна (150–200 мс), не частотой кадров видео. Выключение немедленно завершает переходы. В скрытом или свёрнутом окне анимации останавливаются независимо от этой настройки.
- **Уведомление о сохранении**: по умолчанию включено; управляет сообщением Windows после успешного экспорта. Сообщения об ошибках и обновлениях этим переключателем не отключаются.
- **Звук при сохранении**: по умолчанию выключен. Включает отдельный системный сигнал после успешного экспорта. Звуки самих уведомлений Windows зависят от настроек Windows.

Общие параметры можно менять во время записи. Захват, звук и хранение доступны после остановки буфера: они не перезапускают работающий захват неожиданно. Одна кнопка **«Сброс» внизу экрана** возвращает все дополнительные параметры к значениям по умолчанию, включая стандартную папку буфера. Обычные настройки — монитор, FPS, битрейт, длительность, режим звука, горячая клавиша и папка готовых MP4 — не меняются. Общий сброс во время записи заблокирован.

Поля размещены компактно, без описаний. Зелёная прокрутка поддерживает колесо, перетаскивание бегунка, Home/End и PageUp/PageDown. Колесо над полем громкости прокручивает экран, не меняя случайно громкость. Параметры сохраняются автоматически; при отказе записи файла внизу отображается ошибка. В таком случае сохранение на диск не подтверждено.

## Обновления

Большая кнопка проверки убрана из основного окна. Нажатие **на логотип слева от ReplayLite** открывает существующее окно проверки обновления. Для более новой версии на логотипе появляется зелёная точка, действие также доступно в трее. Наведение на логотип показывает подсказку. Само нажатие логотипа не устанавливает обновление: скачивание и замена начинаются после отдельного подтверждения в окне обновления.
