# План: настройки ReplayLite — предварительный вариант 0.4

## Цель и границы
Шесть вкладок со значками: захват, файлы, видео, аудио, клавиши и отклик, Windows. Готовые темы доступны в системной вкладке. Единственное меню без расширенного уровня; компактные поля, подсказки «?», один сброс. Шестерёнка под статусом, главная без заголовка «Запись».
Исходная версия 0.3.16, main, чистый Git. WinForms/.NET Framework 4.8, FFmpeg 9.0.2, NVENC. Совместимость старых настроек обязательна.
Выпуск: по прямому условию пользователя номер 0.4.0 и релиз — только после одобрения предварительного результата. Сейчас VERSION не меняется, коммит и push разрешены.

## Сценарии
- Старый файл настроек, неверные значения, безопасные значения по умолчанию, атомарное сохранение.
- Шесть вкладок, вопросы, переключение с активным вводом клавиш, блокировка захвата во время записи, доступность системных предпочтений.
- MP4/MKV, имена с токенами и коллизиями; отказ экспорта сохраняет сегменты; повторное сохранение и остановка.
- H.264/HEVC/AV1 и CBR/VBR: реальный NVENC и декодирование, доступность зависит от GPU. Исходное разрешение — GPU; по явному ответу пользователя 720p/1080p — CPU с предупреждением. Никакого незаметного переключения.
- Система/микрофон независимо, устройства отсутствуют, громкость 0/100, восстановление.
- Уведомления, короткие звуки с отдельной громкостью, автозапуск, закрытие/трей, старт свёрнутым, тихая проверка обновлений.
- Темы, возврат к исходной палитре, сброс, отсутствие активных анимаций в скрытом окне.
- Базовые проверки source/check-*.ps1 в изолированной Portable-копии; аппаратные и синтетические результаты отдельно.
- Сравнение скрытого окна и записи с базой; GPU/VRAM и игровой frame time при отсутствии достоверного счётчика не объявлять проверенными.

## Найденные обстоятельства
- scale_d3d11 в закреплённом FFmpeg возвращает 80070057; D3D12 interop отсутствует. Пользователь явно разрешил масштабирование через CPU с предупреждением. Исходное разрешение остаётся GPU.
- AV1 нельзя сегментировать в MPEG-TS: использовать Matroska для AV1, сохранить TS для старого пути H.264.
