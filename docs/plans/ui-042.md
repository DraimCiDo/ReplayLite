# ReplayLite 0.4.2 — обновления, тексты и мягкие темы

## Цель и границы

Запрос 29 октября 2026: отдельная Lucide-кнопка обновлений возле шестерёнки, своевременная индикация новой версии, увеличенное название без обрезанного y, понятная справка без повторного заголовка, фактический путь буфера, удаление выбора устройства вывода, полноценные мягкие палитры.

База main b8ce2fa, VERSION 0.4.1, Git чистый. Среда Windows x64/.NET Framework 4.8, существующие FFmpeg/NVENC/NAudio. Основные точки: MainForm.cs, Ui.cs, AdvancedSettings.cs, Branding.cs, LanguageUi.cs, Localization.tsv, встроенные UI/live-тесты. Системное перетаскивание не меняется. Выбор другого варианта общей компоновки остаётся отдельным решением; текущую сетку не заменять без выбора. Установленная копия пользователя не меняется.

Автопроверки используют существующий секундный служебный timer: асинхронный запрос не чаще 5 минут, запуск/возврат в окно учитывают этот срок; без сервера push мгновенная доставка не гарантируется. Настройка автоматической проверки сохраняется. Индикация — не более трёх миганий, затем постоянная отметка; скрытие/минимизация прекращают мигание. Загрузка и установка требуют нажатия пользователем, запись штатно завершается существующим updater.

Системный звук следует устройству Windows по умолчанию; скрытый старый SystemDevice не должен незаметно оставлять привязку. Совместимость формата старых настроек и тестовых AudioPipe сохраняется.

## Сценарии и доказательства

До/после — тот же UI helper, та же вкладка и аппаратная среда, idle/move/hover, 3 прогона с прогревом; физический drag не подменяется программным. Изменений capture/движения нет; сравнений игрового FPS и конкурентов не заявлять. CPU приложения и FFmpeg отдельно, клип проверить ffprobe и декодированием.

Автопроверки: без параллельных запросов; выключение во время запроса; отмена на выходе; офлайн/текущая/новая/повторная версия; видимое/скрытое/минимизированное окно; мигание заканчивается. Новые тесты не обращаются к настоящему GitHub вместо детерминированной фикстуры.

Справка: обе локали, длинный путь, настройки по умолчанию и выбранная папка, disabled-параметры, клавиатура. Старый SystemDevice удалён из UI, формат настроек читается; выбранный микрофон не заменяется. Палитры менять во время записи без рестарта, дескрипторы стабильны после прогрева.

Базовые команды: source/build.ps1, check-build.ps1, check-buffer.ps1, check-audio.ps1, check-capture-recovery.ps1; package.ps1, check-deployment.ps1, check-installer.ps1. Live-сценарий — изолированный --advanced-live-test с RU/EN, экспортом и проверкой файла. Коды выхода и пути к свежим отчётам добавить по факту.

## Находки / фактический результат

Пользователь явно исключил дальнейшие проверки «тряски» окна. Прогоны перемещения больше не запускать, незавершённую серию остановить; физический drag не является критерием этой задачи. Дальнейшая проверка ресурсов ограничивается простоем, конечностью индикации, дескрипторами и настоящей записью. Числа движения из промежуточных серий не считать доказательством регрессии/улучшения.

Уточнения: обновление показывается только на главном экране, в настройках скрывается и не мигает. Найденный серый прямоугольник в битрейте — редактор NumberBox создавался до применения сохранённой палитры. Добавлена синхронизация цветов дочернего TextBox при изменении цветов владельца и тест холодного запуска с другой палитрой.

Последнее уточнение: версия размещается мелко над концом названия, правый край совмещается с последней буквой по измеренной ширине текста. Это заменяет прежнее выравнивание версии по оси логотипа; название и логотип остаются отцентрированы между собой.

Уточнение пользователя: отцентрировать заголовок раздела относительно кнопки «Назад», а название/версию — относительно логотипа. Добавлена общая вертикальная ось и проверка центров; визуальная проверка входит в P5.

P2: три прогона базы завершились с кодом 0. idle CPU 0–0.012%; программное move 0.097–0.134%; hover 0.073–0.183%, без erase. Это UI-проба, не физический drag. Исходники функциональных изменений собраны (код 0), новые UI-проверки прошли, включая состояния обновления/интервал/отключение/ошибку, палитры и пути. После уточнения выравнивания и добавления проверки GDI нужна новая сборка/повтор UI.

До правок: update-кнопкой служит логотип; фон проверяет раз в 6 часов; выключение настройки после первой проверки не останавливает дальнейшее расписание. Tooltip повторяет название, дефолтная папка скрыта словом «По умолчанию»; тёмные темы отличаются главным образом акцентом. Реализация и проверки нового поведения пока не выполнены.
