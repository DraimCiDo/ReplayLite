## Найденные дефекты и изменения плана

Отчёт 0.4.1 содержит незаполненную секцию публикации: проверить реальное состояние отдельно, не считать старый текст доказательством отсутствия релиза.

Физический профиль 0.4.1: один зарегистрированный проход 13.482 с, 12828 WM_WINDOWPOSCHANGED, 6.2031 с CPU, 2.876% всех 16 логических CPU; 483.56 мс CPU на 1000 перемещений. Счётчик QueryThreadCycleTime указывает основную долю циклов внутри нативного WM_SYSCOMMAND (цикл перемещения), вне вложенных обработчиков; WM_PAINT всего 7. Это локализация затрат, ещё не точный стек нативной причины. Нужны дополнительные сопоставимые прогоны.

Эксперимент только в игнорируемом диагностическом helper: замена промежуточного RECT в WM_MOVING на предыдущий до 144 Гц. Пользователь сообщил «теперь не передвигается нормально». Подход отклонён, окно остановлено; в исходники программы изменение не внесено. Нельзя выпускать этот способ как оптимизацию. Следующий шаг — профиль нативного стека/сравнение минимального окна либо объединение входных событий без изменения семантики WM_MOVING; дальнейшие прототипы проверять отдельно.

Уточнение пользователя: аналогичное повышение CPU наблюдается при быстром перемещении других приложений Windows. Штатная нагрузка системного цикла не считается сама по себе дефектом ReplayLite. A2 уточнён: прежде чем менять системное поведение, доказать избыток относительно минимального окна. Не продолжать ограничение WM_MOVING и не заявлять доказанное отсутствие избытка без сравнения. Приоритет — выбранная компоновка и оформление.

Макеты содержат локально работающие громкости/переключатели/радиокнопки и варианты справки/языка/палитры. Проверка синтаксиса JavaScript: node --check, код 0. Браузерная визуальная проверка пока недоступна: browser access host unavailable; не выдавать её за выполненную. Макеты не меняют приложение или настройки пользователя.

Предыдущая публикация 0.4.1 дополнительно проверена: CI success, Latest/stable, четыре скачанных файла, три SHA-256, версия и совпадение EXE внутри ZIP; проверка код 0. Секция публикации RELEASE-041-VALIDATION.md дополнена фактическими результатами.
