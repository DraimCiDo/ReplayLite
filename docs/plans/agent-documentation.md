# План и отчёт: документация для агентов

## Цель и границы

Подготовить обязательный процесс работы над ReplayLite: план до реализации, проверка успешных и ошибочных сценариев, исправление найденных багов, доказательная приёмка и контроль низкого расхода ресурсов. Изменяются только инструкции и документация; код программы и зависимости не меняются.

Исходное состояние: корневой `AGENTS.md` содержал общие правила сохранности, Git и анимаций, но не задавал подробный цикл разработки и приёмки. В проекте есть автоматические и аппаратные тестовые режимы. В текущей папке отсутствует `.git`: `git status --short` завершился с кодом 128; коммит и push здесь недоступны.

Этот файл фиксирует ход документационной задачи; начальный порядок работы был изложен в сообщении перед исследованием, подробный файл составлен при подготовке материалов. Для последующих задач новые инструкции требуют полного плана до реализации.

## Применимость проверок

- Сборка, автоматические тесты приложения и аппаратная запись: `not_applicable`, исходники программы не меняются. Запусков и новых результатов работы программы эта задача не заявляет.
- Замеры ресурсов: `not_applicable`, исполняемое поведение не меняется. Подготовлена методика для следующих изменений.
- Локальные ссылки, соответствие команд исходникам, UTF-8 и просмотр итоговых правок: обязательны для текущей задачи.
