Дата: 29 октября 2026. Исходная main 41d9572, VERSION 0.4.0, Git чист. Пользователь сообщил CPU 4–5% даже при выключенной записи и поручил 11 изменений.

## Результат и границы
Исправить нагрузку интерфейса, контраст отключённых элементов и заголовок Windows; убрать настройку анимаций и успешные сообщения сохранения; перейти на Lucide; тематические логотип/трей со статусами; RU/EN; предложить варианты компоновки и подсказок для выбора пользователем.
Готовая компоновка выбирается пользователем после просмотра вариантов. До этого независимые исправления выполняются полностью; не выдавать выбранный дизайн и выпуск всей задачи за завершённые. После выбора — один проверенный PATCH-релиз (ожидается 0.4.1) по правилам проекта, без перезаписи 0.4.0.
Не менять установленную копию, её настройки и текущую запись. Не добавлять постоянно работающие эффекты, опрос мыши или CPU-копирование видео.

## Сценарии
- Поведение idle, скрытого окна, движения только собственного окна и частого hover; запись выключена. CPU приложения отдельно от FFmpeg и DWM. Синтетическое движение не равно физическому перетаскиванию — фиксировать границу проверки.
- Все темы, активные/отключённые элементы, фокус и отсутствие заливок системным чёрным/белым.
- Активация/деактивация окна, Windows без поддерживаемого backdrop, отключённые системные эффекты.
- Трей: idle, запись, сохранение, ошибка, доступное обновление (отдельный значок только в трее), тема/язык меняются во время записи без перезапуска.
- Старый settings.txt с Animations; неверный/отсутствующий Language, оба языка и длинные названия/ошибки/устройства; пользовательские пути и имена не переводятся.
- Глобальные клавиши, источник захвата, буфер, экспорт/ошибка/восстановление, установщик и обновление.
- Значимые новые тесты; source/check-*.ps1 на свежей сборке и отдельная аппаратная запись.
