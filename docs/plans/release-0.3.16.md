# План выпуска 0.3.16

Пользователь явно поручил опубликовать новый билд в GitHub Releases. Версия `0.3.16` и changelog уже подготовлены, программные изменения проверены локально; CI программного коммита `323bdfa` и повышения версии `8d3aed9` завершился успешно. Повышать номер ещё раз не требуется: тег и релиз `v0.3.16` на момент начала задачи отсутствуют.

## Критерии приёмки

- Локальный пакет имеет версию 0.3.16, проверки установки/обновления проходят; существующие доказательства поведения сохраняются.
- Новый тег `v0.3.16` указывает на проверенную `main`, без переноса старых тегов.
- Build и release jobs для тега завершены успешно.
- Релиз опубликован как стабильный Latest и содержит Setup, Portable ZIP, EXE и SHA256SUMS.
- SHA-256 скачанных файлов совпадает с опубликованными контрольными суммами; пользователь получает ссылку на Release.

При отказе CI сначала изучается причина. Сбой среды допускает повтор того же workflow; изменение исходников требует новой PATCH-версии и тега. Старые опубликованные теги и версии не перезаписываются. Неполный draft не считается выпуском. Новые замеры производительности для одного выпуска без изменения программного поведения не нужны; исходные результаты находятся в [отчёте](../ADVANCED-SETTINGS-VALIDATION.md).

Фактическое завершение CI и публикации проверяется после отправки тега и фиксируется ссылкой на GitHub Release в итоговом сообщении.
