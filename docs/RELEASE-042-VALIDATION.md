# Проверка ReplayLite 0.4.2 — 29 октября 2026

## Объём

Исходная main b8ce2fa, версия 0.4.1; рабочая копия была чистой. Новые изменения: отдельная кнопка обновления только на главном экране; асинхронная автопроверка раз в 5 минут, ограниченное мигание и постоянная отметка; увеличенное и выровненное название, версия над концом названия; справка без повторного заголовка с новыми RU/EN-текстами; фактический путь буфера; системный звук с устройства Windows по умолчанию без выбора вывода в UI; четыре мягкие полноценные палитры.

Дополнительно исправлены обнаруженные дефекты: выключение автопроверки не останавливало старое расписание; ручное открытие обновлений могло запускать параллельную фоновую проверку; внутренний TextBox битрейта сохранял цвет прежней темы при холодном запуске. Формат старых настроек сохранён; скрытая привязка SystemDevice сбрасывается только в конфигурации приложения, при чтении старого файла остальные данные не переписываются.

Настоящие изменения положения окна и системный цикл перетаскивания не менялись. Пользователь исключил дальнейшие проверки «тряски». Новая общая компоновка и полноценный Mica не входят в эту поставку; старые ограничения не объявляются исправленными.

## Среда

Windows 11 Pro 10.0.26300, AMD Ryzen 7 5700X / 16 логических процессоров, NVIDIA GeForce RTX 4060 / драйвер 32.0.16.2101, монитор 2560×1440. .NET Framework 4.8, закреплённые FFmpeg/NVENC и NAudio без новых runtime-зависимостей. Тестовая Portable-копия и записи: `.deps-cache/ui-042/candidate`; установленная копия пользователя не изменялась.

## Ресурсы и ограничения

После прогрева 20 переключений палитр: прирост GDI **0**, USER **0**. Анимационных таймеров контролов нет; мигание использует существующий служебный таймер с конечным счётчиком, скрытие прекращает его. Автопроверка — не более одного асинхронного запроса в 5 минут при включённой настройке, с существующим таймаутом 15 секунд. Фон ничего не скачивает и не устанавливает самостоятельно.

До исключения перемещений пользователем были сняты промежуточные программные пробы. Наблюдались внешние перерисовки/erase в «простое» и различающийся поток событий; эти числа не являются контролируемым доказательством изменения CPU. Дальнейшее перетаскивание не проверялось по прямому указанию пользователя. Короткий скрытый UI-тест показал приращение CPU 0.000 с, что не означает нулевого потребления в длительном простое. Сравнения игрового FPS, GPU/VRAM, конкурентов и многочасовой стабильности не проводились.

Снимки DrawToBitmap проверяют клиентскую область; они не доказывают видимый DWM/Mica. Аппаратный тест доказывает короткую реальную запись и экспорт, а не все физические отключения устройств или все конфигурации DPI.
