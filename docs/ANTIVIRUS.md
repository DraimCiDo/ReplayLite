# Проверка антивирусами

Для ReplayLite-Setup.exe 0.3.2 проверен [отчёт VirusTotal](https://www.virustotal.com/gui/file/474227eefedbdd04d74e250f269799d87f5dbf5167c3da63a88dc7940edd3430/detection) от 14 октября 2026. SHA-256 совпал с опубликованным GitHub Releases файлом. На момент проверки: 4/64 — Bkav Pro, McAfee Scanner, SecureAge, Trapmine. Microsoft Defender не обнаружил угрозы, Kaspersky завершился по тайм-ауту. Общие и ML-названия детектов не доказывают ложное срабатывание; часть анализа поведения ещё не завершилась.

Версия 0.3.2 использовала самописный .NET-установщик со сжатым `payload.zip` около 100 МБ внутри `.text`. В 0.3.3 установка переведена на стандартный Inno Setup: отдельные файлы пакета, обычный установочный движок, без ZIP внутри managed-кода. Это улучшение упаковки, а не подтверждение снятия детектов. В сборке нет обфускации, шифрования исполняемых файлов или UPX. Контрольные суммы и проверка доверенных зависимостей сохранены.

Новые файлы требуют отдельного сканирования: результаты старого хеша к ним неприменимы. Для проверки используйте опубликованный установщик и сверяйте SHA256SUMS.txt. Если срабатывание сохраняется, нужно проверить отдельные компоненты и обратиться в лабораторию соответствующего вендора с файлом, хешем, ссылкой на исходники и описанием воспроизводимого поведения. Без ответа лаборатории не объявляйте детект ложным.

Подпись и предупреждение SmartScreen описаны в [SIGNING.md](SIGNING.md). Подпись компилятора Inno Setup не является подписью ReplayLite; наш установщик пока не подписан. Microsoft отдельно описывает [подачу файла разработчиком и отличие SmartScreen от антивируса](https://learn.microsoft.com/en-us/defender-xdr/developer-faq).
