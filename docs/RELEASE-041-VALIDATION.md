# Проверка ReplayLite 0.4.1 — 29 октября 2026

## Объём выпуска

Пользователь попросил опубликовать готовую часть, а окончательную компоновку и оставшиеся исправления перенести на завтра. Этот выпуск не объявляет все 11 пожеланий выполненными и не заявляет полного устранения нагрузки CPU.

Готовая часть: тематические отключённые подписи/поля/кнопки; удаление настройки анимаций и её таймеров, успешной надписи сохранения; официальные Lucide и тематический знак/трей; справка рядом с названиями, тематический tooltip; DWM-цвета заголовка; RU/EN с сохранением языка. Начальная оптимизация управляемых уведомлений при перемещении включена, конечные координаты проверяются.

Исходная main 41d9572, версия 0.4.0. Окончательная сборка 0.4.1.0. Новых runtime-пакетов нет: Lucide преобразуется во встроенный атлас на этапе сборки средствами установленного .NET Framework/WPF.

## CPU: подтверждённая проблема, частичная правка

Пользователь физически перетаскивал отдельные диагностические окна с выключенной записью. База 0.4.0: 4.924% / 7.973 с / 5763 сообщения и 4.694% / 9.799 с / 7139 сообщений. Кандидат: 5.083% / 4.246 с / 3679 сообщений и 4.756% / 6.550 с / 6007 сообщений; 3439 и 5628 уведомлений отложены соответственно. Изменения размера/видимости/рамки не объединяются; при завершении перемещения координаты сверяются с нативным окном.

Частота перемещения различалась: примерно 723/729 сообщений в секунду против 866/917. Пользователь отметил снижение нагрузки и нормальное движение, однако исходные проценты **не доказывают устранения CPU-дефекта**. Нормирование даёт примерно 1.09/1.03 мс CPU на событие у базы и 0.94/0.83 мс у кандидата, но это только два неуправляемых прогона. Полная оптимизация и строго сопоставимый тест остаются на следующую сессию.

Обычное программное перемещение не воспроизводило физическую нагрузку и не считается доказательством исправления. Дополнительные анимационные таймеры удалены; UI-тест подтверждает ноль активных анимаций. Новых замеров игрового FPS, GPU/VRAM и превосходства над конкурентами нет.

## Отложено по запросу пользователя

- Найти оставшийся источник CPU и проверить не менее трёх сопоставимых прогонов.
- Показать варианты компоновки и объяснений, получить выбор, затем реализовать выбранный.
- Подтвердить видимый Mica/Backdrop или доработать шапку с безопасным fallback; один вызов DWM API не равен подтверждению прозрачности.
- Дополнительно оценить логотип/значки 16–32 px, DPI/длинные строки, настоящий язык во время записи и редкие сообщения.

Полный промпт: [NEXT-SESSION-PROMPT.md](NEXT-SESSION-PROMPT.md). Источник и лицензия Lucide: [THIRD-PARTY.md](../THIRD-PARTY.md). Официальные API: [WM_WINDOWPOSCHANGED](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-windowposchanged), [DWM attributes](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute).
