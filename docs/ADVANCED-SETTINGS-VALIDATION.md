## Найденные проблемы и ограничения

- Ранняя реализация создавала расширенные контролы при запуске. После замеров создание перенесено на первое открытие; финальные замеры скрытого UI приведены выше.
- Исправлены повторные подключения явно выбранного аудиоустройства из-за событий другого endpoint, несоответствие фона кнопок вложенной панели, тесное поле числа 10240 и оформление пути буфера. Изменения общего сброса защищены проверкой сохранности обычных параметров.
- Дважды воспроизведён отказ `Compress-Archive` при совместном чтении исходных ZIP. Установлено эксклюзивное открытие входных файлов в модуле Windows PowerShell Archive. Использован .NET `ZipFileExtensions.CreateEntryFromFile` с явными именами ZIP-entries через `/` и заменой готового ZIP после успеха. Фикстура с удерживаемым shared-reader и весь package/deployment/installer прошли. Защита Windows не отключалась.
- Аппаратное масштабирование исключено: `scale_d3d11` в закреплённой сборке не прошёл живой тест GPU-текстуры (`80070057`). CPU-масштабирование не добавлялось; разрешение исходное.
- В промежуточных видимых UI-прогонах были два нестабильных отказа старых сценариев (проверка popup и фонового запуска). Диагностика разделена и дополнена состояниями; на финальных сборках сценарии прошли. Причина тех промежуточных отказов не установлена, исправление неизвестной причины не заявляется.
- Пользователь остановил computer-use клавишей Escape. После этого глобальный ввод не отправлялся; новые элементы проверены автоматическими обработчиками/границами и живым тестом приложения. Финальная субъективная визуальная оценка после последних правок не заменяется утверждением об «идеальном» дизайне.
- Физическое отключение устройств, акустическое качество/синхронизация, HDR и все варианты драйверов не проверены. Обновление из нового публичного релиза не проверялось: релиз не создавался. Установка выполнялась только в тестовые каталоги, рабочая установка пользователя не менялась.
