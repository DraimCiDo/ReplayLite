# Проверка выпуска ReplayLite 0.4.0

Дата: 29 октября 2026, Europe/Riga. Пользователь одобрил публикацию глобального обновления. Изменены VERSION, changelog и актуальные документы; поведение программы относительно проверенного предварительного варианта не менялось.

## Локальная проверка

Все команды завершились с кодом **0**:

- `source/build.ps1`: приложение, UpdateHelper и Uninstall имеют FileVersion 0.4.0.0.
- `source/check-build.ps1`: UI, шесть разделов, темы, горячие клавиши, автосохранение, сброс, ошибки и скрытые анимации.
- `source/check-buffer.ps1`: отказ экспорта, сохранность/очистка буфера, отсутствие повторных кадров, три декодируемых клипа и сохранение при остановке.
- `source/check-audio.ps1`: ошибки устройств, отключение/возврат микрофона и смена системного устройства без остановки видео.
- `source/check-capture-recovery.ps1`: потеря рабочего стола, DDA/WGC, восстановление, изменение размера и shutdown.
- `--preferences-hardware-test`: настоящий NVENC H.264/HEVC/AV1, MP4/MKV, CBR/VBR, 720p/1080p, отдельные источники аудио; ffprobe и декодирование всех клипов, сохранность при ошибочном шаблоне и восстановление AV1.
- `source/package.ps1`: ZIP, EXE и установщик собраны; release notes соответствуют секции 0.4.0.
- `source/check-deployment.ps1` и `source/check-installer.ps1`: контрольные суммы, обновление/откат, настоящий установщик обоих режимов в тестовых папках.

Изолированная Portable-копия: `.deps-cache/release-040`. Установленная программа, её настройки и текущая запись не изменялись. Локальный EXE SHA-256: `677F72946404D0167CCF817D5C5E1729ABB4B508C38D2ACB43029A8EAF01B6A5`.

Среда, аппаратные ограничения и замеры предварительного варианта: [SETTINGS-V04-VALIDATION.md](SETTINGS-V04-VALIDATION.md). Замеры не повторялись для изменения только номера версии; новых заявлений о производительности нет. Масштабирование через CPU по-прежнему явно обозначено и отключено по умолчанию.
