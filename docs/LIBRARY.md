# Повторы и встроенный просмотр

Кнопка с папкой возле обновления и настроек открывает библиотеку. Две прежние нижние кнопки убраны. Библиотека читает текущую папку сохранения; временные сегменты буфера в неё не попадают.

На странице две карточки MP4/MKV: превью, длительность, имя, дата изменения и размер. Кнопки Lucide позволяют смотреть видео внутри ReplayLite, показать файл в Проводнике, скопировать путь или отправить файл в корзину. Название действия видно при наведении. Удаление требует подтверждения; при ошибке корзины безвозвратного удаления нет. Сетевые и неподдерживаемые диски для этого не используются.

Плеер поддерживает паузу, перемотку и отдельную громкость. Стрелка возвращает к карточкам, следующая — на главную. При скрытии/минимизации окна просмотр ставится на паузу и декодер останавливается. Запись буфера продолжается независимо от просмотра.

Список обновляется после изменения папки, при повторном открытии или кнопкой «Обновить». Папка открывается отдельной кнопкой внутри библиотеки. Повреждённый или исчезнувший файл показывает ошибку, остальные клипы доступны.

## Расход ресурсов

- Превью и метаданные читаются последовательно только для двух видимых карточек. Кеш ограничен 12 записями; размер/время изменения файла инвалидируют запись.
- Каталог сканируется в фоне без рекурсии, до 20 000 файлов. При достижении лимита есть отметка. Reparse point и частичные/временные файлы исключаются.
- FileSystemWatcher работает только в открытой библиотеке без плеера; события объединяются однократной задержкой 350 мс. Постоянного опроса папки нет.
- Используются существующие FFmpeg и NAudio. Предпочитается D3D11VA; при отказе до первого кадра есть один переход на CPU с сообщением. Одновременно работает не более одного процесса метаданных/превью/просмотра, отдельно от записи.
- Просмотр использует два ограниченных буфера 640×360, один Bitmap и PCM-буфер до секунды. UI получает последний готовый кадр, очередь не растёт. Копирование кадров относится только к просмотру: GPU/NVENC-захват и экспорт без перекодирования сохранены.

Об аппаратном декодировании и цене копирования кадров: [FFmpeg](https://ffmpeg.org/ffmpeg.html). [Фактические проверки](RELEASE-043-VALIDATION.md).
