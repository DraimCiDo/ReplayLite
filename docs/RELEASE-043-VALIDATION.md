# Проверка ReplayLite 0.4.3 — 29 октября 2026

## Объём

База d9f446d / 0.4.2, Git был чистым. Добавлены библиотека MP4/MKV и встроенный плеер с паузой/перемоткой/громкостью; две нижние кнопки удалены. Библиотека открывается кнопкой возле настроек. Название и версия рисуются в одной области с кешируемыми видимыми границами букв: версия непосредственно над последней «e», название выровнено с логотипом. Значки окна и собственных закреплённых ярлыков меняют палитру.

Пользователь подтвердил видимость версии и смену значка TaskBar в тестовой копии; после уточнения положения версия перепроверена на свежем снимке. Новых runtime-зависимостей нет. SVG Lucide `copy` и `trash` неизменёнными взяты из прежнего commit be09619c1c1124ad09c19fc3e87ee3b939409bbd. [Библиотека](LIBRARY.md), [план](plans/library-043.md).

## Исправленные найденные дефекты

- Версия перепозиционировалась во время DPI-масштабирования. Общая область рисования убрала зависимость от порядка SizeChanged/FontChanged. Проверены видимые границы и контрольные размеры/шрифты 100/150/200%; настройки Windows не менялись.
- Закреплённый значок мог брать статический ресурс. Обновляются WM_SETICON и IconLocation только `.lnk`, чей TargetPath совпадает с текущим EXE, с адресным уведомлением Shell. Общий кеш не очищается, Explorer не перезапускается.
- FFmpeg отказывался писать PCM в существующий собственный именованный канал без `-y`. Флаг добавлен; повтор плеера прошёл.
- Тест корзины поймал AccessViolation: IUnknown вместо IShellItem в DeleteItem. Используется типизированный интерфейс. Повтор подтвердил отмену, отказ без удаления и настоящую корзину для тестового файла.
- Локализация и tooltip удерживали удалённые элементы. Ссылки очищаются; WeakReference старой карточки освобождается после перелистывания.
