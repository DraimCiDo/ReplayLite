# Подпись Windows-релизов

Сейчас доверенный сертификат и аккаунт SignPath к проекту не подключены. Выпускаемые файлы пока **не подписаны**. Добавленный этап подписи не означает, что сертификат уже выдан или предупреждение Windows устранено.

Сообщение «Система Windows защитила ваш компьютер» относится к Microsoft Defender SmartScreen. Подпись устанавливает проверяемого издателя, но новому файлу даже с доверенной подписью может потребоваться репутация. Самоподписанный сертификат не подходит для публичного распространения. См. [документацию Microsoft](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/code-signing-options).

## Подключение SignPath

1. Владелец проекта создаёт аккаунт и подключает репозиторий к [SignPath](https://docs.signpath.io/trusted-build-systems/github).
2. Для бесплатного сертификата [SignPath Foundation](https://signpath.org/terms.html) нужен одобренный проект с OSI-совместимой лицензией. Собственный код ReplayLite опубликован под MIT в корневом LICENSE; заявление владельца и одобрение сервиса требуются отдельно. Лицензии зависимостей уже перечислены в THIRD-PARTY.md. Одобрение Foundation не гарантировано.
3. Настройте проект, политику подписи для доверенных тегов и две конфигурации артефактов: `application` для ZIP с `ReplayLite.exe`, `UpdateHelper.exe`, `Uninstall.exe`; `setup` для ZIP с `ReplayLite-Setup.exe`. Подписываются только собственные бинарные файлы, с Authenticode и timestamp; FFmpeg и NAudio не переподписываются.
4. В GitHub Settings → Secrets and variables → Actions добавьте secret `SIGNPATH_API_TOKEN`. Не сохраняйте токен в исходниках или сообщениях.
5. Добавьте repository variables `SIGNPATH_ORGANIZATION_ID`, `SIGNPATH_PROJECT_SLUG`, `SIGNPATH_SIGNING_POLICY_SLUG`, `SIGNPATH_APP_CONFIGURATION` и `SIGNPATH_SETUP_CONFIGURATION`. Указывайте реальные значения одобренного проекта; organization ID включает этап подписи только для push тегов.

Сборка сначала подписывает приложение и помощников, проверяет доверенную подпись и timestamp, затем включает эти файлы в Portable ZIP и установщик. После подписи установщика контрольные суммы пересчитываются. Если настроенная подпись не удалась, публикация релиза останавливается; перехода к неподписанным файлам нет.

Сервисная часть пока не проверена: нет аккаунта, токена и одобренного сертификата. Локально проверяется отказ на неподписанных файлах; CI без настройки продолжает выпускать явно неподписанные сборки. Защита Windows и хранилище доверенных корневых сертификатов не изменяются.

Готовые публичные сведения для заявки: [SIGNPATH-APPLICATION.md](SIGNPATH-APPLICATION.md).
