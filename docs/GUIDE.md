# Подробная инструкция ReplayLite

[Вернуться к странице проекта](../README.md)

Локальное приложение для Windows 10/11 x64 и видеокарт NVIDIA с NVENC. Эта сборка проверена на RTX 4060. Для записи интернет и права администратора не нужны. Для скачивания обновлений нужен интернет. Требуется .NET Framework 4.8, обычно уже установленный в Windows 10/11.

Репозиторий содержит исходники. Для сборки после клонирования выполните в PowerShell:

```powershell
git clone https://github.com/DraimCiDo/ReplayLite.git
cd ReplayLite
.\source\setup-deps.ps1
.\source\build.ps1
.\ReplayLite.exe
```

На этапе загрузки зависимостей нужен интернет. Скрипт скачивает закреплённые версии NAudio 1.10.0 и FFmpeg 9.0.2 с проверкой SHA256, без установки в систему. После сборки приложение работает локально без сети.

## Использование

1. Запустите `ReplayLite-Setup.exe` и выберите установку или Portable; либо распакуйте весь `ReplayLite-Portable.zip`. Запустите `ReplayLite.exe`.
2. При необходимости откройте вкладку **Настройки**: выберите экран, длительность, звук, качество и папку сохранения. Изменения сохраняются автоматически. По умолчанию: **2 минуты, 30 FPS, 8 Мбит/с, компьютер + микрофон**.
3. Вернитесь на вкладку **Запись** и нажмите **Начать запись**. Фоновую запись нужно включить до события, которое вы хотите сохранить. Через несколько секунд появятся первые готовые кадры и станет доступно сохранение.
4. Нажмите **Ctrl+Shift+F9** или кнопку сохранения. Повтор появится в выбранной папке в формате MP4. После успешного сохранения использованные фрагменты очищаются, счётчик и полоса заполнения сбрасываются к новым данным. Захват продолжается: кадры, снятые во время экспорта, остаются для следующего клипа. Ошибка сохранения не очищает буфер.
5. Закрытие окна отправляет приложение в трей. Чтобы остановить и завершить приложение, выберите **Выход** в меню значка.

В интерфейсе есть отдельная панель записи, карточки CPU/RAM/буфера/диска, кнопки открытия папки и последнего повтора. Список выбора поддерживает мышь, стрелки и Space/Enter. Папка меняется кнопкой **Сменить папку** при остановленном буфере.

Значок трея имеет четыре состояния: серый — буфер выключен, бирюзовый — идёт запись, синий — запуск/остановка/сохранение, красный — ошибка. Пункты меню трея включаются и выключаются вместе с кнопками окна. Собственный значок также встроен в EXE.

Анимации кнопок, статуса и шкалы длятся 150–200 мс и запускаются только при изменении. Постоянных анимаций нет. После скрытия или минимизации окна таймеры анимаций останавливаются; вычисление метрик окна пропускается, а контроль состояния записи продолжает работать. Иконки всех состояний создаются один раз и повторно используются.

Записывается весь выбранный экран в исходном разрешении, включая курсор. Монитор выбирается по модели и разрешению; номера выходов DXGI программа сопоставляет самостоятельно. Если экран недоступен для захвата через NVIDIA, кнопка запуска отключена и в окне показана подсказка. Запись отдельного окна не реализована.

## Расход ресурсов

- Захват — Desktop Duplication (`ddagrab`) с кадрами D3D11; кодирование — H.264 NVENC. Программного fallback-кодировщика нет.
- Кадры видео не передаются через управляемую память C#. Предпросмотр отсутствует. FFmpeg запускается с приоритетом `BelowNormal`.
- NVENC использует быстрый preset `p1`, без B-кадров и lookahead, с четырьмя поверхностями. Это уменьшает затраты, но при равном битрейте качество может быть ниже, чем у более медленных preset.
- Уже сжатые двухсекундные фрагменты хранятся на диске. Число фрагментов ограничено длительностью буфера плюс примерно 10 секунд запаса. Сохранение выполняет копирование потоков в MP4 без повторного кодирования.
- При настройке 8 Мбит/с запись пишет примерно 1 МБ/с. Для двухминутного буфера с запасом требуется около 130 МБ; сохранённые повторы занимают дополнительное место и автоматически не удаляются.
- Звук компьютера снимается через WASAPI loopback, микрофон — через WASAPI с устройств по умолчанию. Два входа смешиваются в одну стереодорожку AAC 48 кГц. Небольшие аудиобуферы ограничены 500 мс на вход, тишина не останавливает запись.
- При отключении Bluetooth-наушников или другого аудиоустройства недоступный вход временно заменяется тишиной. Остальной звук и видеозапись продолжаются с тем же процессом FFmpeg и буфером. Изменение устройств Windows обрабатывается автоматически; недоступный источник повторно открывается не чаще раза в 5 секунд при отсутствии новых событий. Выбранный режим звука сохраняется, а под показателями отображаются фактически доступные источники.
- CPU и RAM в окне учитывают приложение и процесс записи FFmpeg. CPU нормирован на все логические процессоры. Это не измерение потери FPS в игре.

Фактические результаты живой проверки находятся в `VALIDATION.md`. Потребление зависит от разрешения, FPS, нагрузки игры, драйверов и аудиоустройств. Приложение использует GPU для захвата и кодирования и не обещает нулевую нагрузку.

## Поведение и ограничения

- После включения доступна только уже записанная часть; полный двухминутный повтор появится после наполнения буфера.
- Сохранение ждёт закрытия текущего фрагмента, обычно до 2 секунд. Ролик включает момент нажатия и может закончиться до 2 секунд после него. Длительность округляется по границам фрагментов.
- Во время сохранения запись продолжается. Повторные нажатия блокируются до окончания экспорта.
- При аварии приложения Windows Job Object завершает дочерний FFmpeg. После штатной остановки временная папка удаляется. После аварии может остаться один ограниченный буфер в папке настроек `buffer-*`; после закрытия приложения его можно удалить.
- При обычной установке настройки находятся в `%LOCALAPPDATA%\ReplayLite\settings.txt`; у Portable — в `data/settings.txt` рядом с EXE. Автозапуск включается переключателем в настройках. После сна буфер нужно включить заново; смена аудиоустройства обрабатывается без остановки видеозаписи.
- Лучше использовать оконный режим без рамки. Эксклюзивный полноэкранный режим, HDR, защищённый контент и игры с ограничениями захвата отдельно не проверены.
- Для микрофона Windows должна разрешать доступ классическим приложениям. Входы поддерживают моно/стерео; многоканальный вывод 5.1/7.1 нужно переключить на стерео.
- Эта версия использует NVIDIA NVENC. AMD/Intel, захват отдельной игры, выбор отдельных аудиоустройств, шумоподавление и отдельные аудиодорожки не реализованы.
- Нажмите поле сочетания, затем одиночную клавишу или сочетание с Ctrl/Alt/Shift/Win и отпустите все клавиши. Доступны буквы, цифры, F-клавиши кроме F12, навигация, NumPad, мультимедийные и другие обычные клавиши клавиатуры. Tab и Escape тоже назначаются; щелчок вне поля отменяет ввод. Ctrl/Alt/Shift/Win сами по себе не назначаются. Занятые и зарезервированные Windows сочетания отклоняются; прежняя настройка сохраняется. Одиночная клавиша перехватывается приложением глобально и может перестать выполнять привычное действие в игре.
- Исполняемый файл не подписан. Проверка обновлений обращается к GitHub Releases при запуске, раз в шесть часов и по нажатию кнопки. Телеметрии и загрузки записей в облако нет.

## Обновление

Проверка выполняется при запуске и раз в шесть часов, с ограничением 15 секунд на запрос. При новой версии появляется уведомление Windows, кнопка «Обновить до…» и пункт в меню трея. Нажатие уведомления открывает окно обновления. Одна версия уведомляет один раз за сеанс; если уведомления Windows отключены, предложение остаётся в окне и меню трея. Отсутствие сети не прерывает запись.

Для ручной проверки нажмите «Проверить обновления». Скачивание начинается только после кнопки «Обновить до…» внутри окна обновления. Пакет скачивается в ограниченном буфере памяти, проверяется SHA-256, программа закрывается и перезапускается. Настройки, выбранная папка записей и MP4 остаются; текущий несохранённый буфер очищается. При ошибке замены восстанавливаются предыдущие файлы. Portable обновляется в той же папке, обычная установка — на месте, без повторного установщика.

## Автозапуск Windows

Включите «Запускать с Windows» на вкладке настроек. После входа текущего пользователя в Windows программа запускается сразу в трее, без краткого показа окна, и автоматически включает буфер с сохранёнными монитором, звуком, длительностью и качеством. Права администратора не требуются. Переключатель по умолчанию выключен и меняет только запись ReplayLite в [HKCU Run](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys).

Пока Windows готовит экран и звуковые устройства, возможны до трёх попыток запуска с паузой 3 секунды. При окончательной ошибке окно не открывается: значок показывает ошибку и появляется уведомление. Откройте приложение из трея для подробностей. Открытие окна при работающем буфере продолжает ту же запись. Обычный ручной запуск EXE по-прежнему ожидает кнопку «Начать запись».

В Portable не перемещайте папку после включения автозапуска. При переносе выключите его в старой копии и включите в новой. Обычный деинсталлятор удаляет автозапуск, если он относится к удаляемой копии. Настройки автозагрузки Windows также могут отключать запуск приложения.

Поворот экрана сохраняется как MP4 display matrix, без обработки каждого кадра. Проигрыватель должен поддерживать эти метаданные (проверено декодером FFmpeg).

Обычная установка удаляется через «Установленные приложения» Windows; данные пользователя остаются. Малый Uninstall.exe, работающий во время удаления, и пустые папки можно затем удалить вручную. Portable удаляется вручную вместе с папкой; предварительно сохраните нужные записи.

## Исходники и сборка

Код приложения находится в `source/`. Выполните `source/build.ps1` из PowerShell. Используется существующий компилятор .NET Framework из Windows; .NET SDK для пересборки не нужен. В переносимой папке `NAudio.dll` уже включена; при клонировании Git сначала запустите `source/setup-deps.ps1`.

Тест записи: `ReplayLite.exe --self-test C:\путь\к\папке both 120`. Тест записывает экран и микрофон, проверяет сохранение, очистку кольца и декодирование роликов. Проверка не воспроизводит звуковых сигналов. Допустимые режимы звука: `both`, `system`, `none`. В тестовой папке остаются MP4 и `self-test.txt`; не используйте тест во время показа конфиденциального содержимого.

Используемые компоненты и источники: [FFmpeg Desktop Duplication](https://ffmpeg.org/ffmpeg-filters.html#ddagrab), [FFmpeg segment](https://ffmpeg.org/ffmpeg-formats.html#segment_002c-stream_005fsegment_002c-ssegment), [NAudio 1.10.0](https://github.com/naudio/NAudio/tree/v1.10.0), [WASAPI loopback](https://learn.microsoft.com/en-us/windows/win32/coreaudio/loopback-recording). Лицензии и версии см. в `THIRD-PARTY.md`.

Проверка интерфейса и отключения анимаций: `ReplayLite.exe --ui-test C:\путь\ui-test.txt`. Живая проверка управления буфером через окно: `ReplayLite.exe --ui-live-test C:\путь\к\папке` — записывает короткий повтор без аудио и восстанавливает пользовательский файл настроек после проверки. Тестовые уведомления со звуком отключены.

Проверка очистки буфера без видеокарты: `source/check-buffer.ps1`. Использует синтетическое видео 64×64, проверяет ошибку экспорта, очистку после успеха, отсутствие общих видеопакетов у соседних клипов, продолжение записи и сохранение одновременно с остановкой. Не записывает экран или аудио. Синтетический кодировщик применяется только в тесте; обычная запись по-прежнему использует NVENC.

Проверка восстановления аудио без физических устройств: `source/check-audio.ps1`. Реальный FFmpeg и две PCM-трубы, синтетические источники и видео 64×64. Проверяются отсутствие устройств при запуске, ошибки открытия/старта/чтения, отключение обоих источников, переподключение и смена устройства по умолчанию, непрерывность процесса и буфера, экспорт и декодирование MP4, освобождение источников. Экран и микрофон пользователя не записываются.
