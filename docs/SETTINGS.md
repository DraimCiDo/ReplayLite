# Настройки ReplayLite 0.4.0

Настройки версии 0.4.0. Интерфейс одобрен пользователем; предварительные проверки и ограничения описаны в [отчёте](SETTINGS-V04-VALIDATION.md).

Шестерёнка под индикатором записи открывает меню. Шесть значков переключают разделы; наведите курсор на значок, чтобы увидеть название. Закруглённая стрелка возвращает на главную. «?» показывает назначение параметра. Изменения сохраняются автоматически; шаблон имени — после Enter или выхода из поля.

| Раздел | Параметры |
| --- | --- |
| Экран и буфер | Монитор и обновление списка, длительность, курсор, папка временных сегментов, резерв диска |
| Сохранение клипов | Папка, MP4/MKV, готовые шаблоны, своё имя и пример результата |
| Видео | 30/60 FPS, исходное разрешение или ограничение 1080p/720p, H.264/HEVC/AV1, битрейт, CBR/VBR |
| Звук | Независимые переключатели системы и микрофона, устройства, раздельные громкости |
| Клавиши и отклик | Глобальная клавиша/сочетание, уведомление, три коротких сигнала, громкость и прослушивание |
| Приложение и Windows | Автозапуск, проверка обновлений при старте, закрытие в трей/выход, старт свёрнутым, анимации, четыре темы |

## Запись и производительность

Исходное разрешение передаёт кадры на GPU без копирования через CPU. Кодирование всегда выполняет NVENC. HEVC и AV1 зависят от поддержки видеокарты; при несовместимости запуск сообщает ошибку, программного кодирования вместо NVENC нет.

**1080p и 720p масштабируются через CPU**, копируют кадры в оперативную память и увеличивают нагрузку. Этот компромисс явно согласован пользователем. По умолчанию выбрано исходное разрешение; предупреждение видно рядом с выбранным масштабированием. Изображение сохраняет пропорции и не увеличивается.

Буфер хранит сжатые двухсекундные сегменты на диске. Для H.264/HEVC используется MPEG-TS, для AV1 — Matroska. Экспорт MP4/MKV копирует потоки без повторного кодирования. Неудачный экспорт не очищает записанные сегменты.

Первые четыре раздела и сброс заблокированы при активной записи. Клавиша сохранения, отклик и системные предпочтения доступны во время записи. Изменение темы не перезапускает захват.

## Имена файлов

Имя задаётся без расширения. Поддерживаются `{date}`, `{time}`, `{monitor}` и совместимый с референсом `{YYYY-MM-DD_HH-MM-SS}`. Пример: `Replay-{monitor}-{date}_{time}`. `{time}` включает миллисекунды. Номер монитора соответствует выходу выбранного адаптера плюс один.

Неизвестные токены, пустое имя, пути, недопустимые символы и зарезервированные имена Windows отклоняются. Предыдущее корректное имя остаётся действующим. При совпадении готового файла добавляется `-2`, `-3` и далее; файл не перезаписывается.

## Windows, звук и темы

- «Запускать с Windows» регистрирует текущий EXE и запускает буфер в трее автоматически. Для Portable нельзя перемещать зарегистрированную папку.
- «Запускать свёрнутым» относится к следующему обычному запуску: окно скрыто, буфер сам не включается. Автозапуск Windows отдельно включает буфер.
- «Закрывать в трей» выключено — крестик останавливает запись и завершает приложение. Команда «Выход» в трее всегда завершает работу.
- Проверка обновлений при старте молчит при отсутствии новой версии и при сетевой ошибке. Новая версия отмечается на логотипе и уведомлением. Нажатие на логотип открывает обновления вручную.
- Громкости системы/микрофона и сигнала сохранения не меняют громкость Windows. Сигнал звучит только после успешного сохранения; прослушивание запускается отдельно.
- Темы «Мята», «Океан», «Лаванда» и «Светлая» применяются сразу. Постоянных таймеров для темы нет. Анимации — короткие переходы; при скрытии прекращаются.
- Один «Сброс» возвращает параметры записи, аудио, отклика, поведения окна и темы к исходным. Монитор, папка клипов, горячая клавиша и регистрация автозапуска сохраняются; это указано в подсказке кнопки.

## Проверка исходников

Сборка и автоматические проверки: [TESTING.md](TESTING.md). Дополнительная аппаратная проверка запускается в изолированной Portable-копии:

```powershell
$process = Start-Process -FilePath .\ReplayLite.exe -ArgumentList '--preferences-hardware-test', 'test-results' -WindowStyle Hidden -PassThru
$process.WaitForExit()
if ($process.ExitCode -ne 0) { throw 'Preferences hardware test failed' }
```

Нужны доступный рабочий стол, монитор на NVIDIA и NVENC с AV1. Тест записывает собственные короткие клипы, проверяет кодек/размер, декодирование, сохранность буфера при ошибочном имени и восстановление AV1 после остановки тестового FFmpeg. Он не управляет установленной копией программы. Отчёт: `test-results/preferences-hardware.txt`.
