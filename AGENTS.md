# Работа над ReplayLite

- Общайтесь с пользователем по-русски.
- После изменений программы проверьте значимое поведение, создайте коммит и отправьте текущую рабочую ветку в `origin`. Пользователь разрешил коммиты и push после изменений; повторное подтверждение не требуется.
- Не публикуйте непроверенный результат как завершённый. Если проверка или push не прошли, сообщите об этом явно.
- Сохраняйте чужие изменения. Не используйте force push.
- Не включайте в Git записи экрана, пользовательские настройки, временные файлы, токены и двоичные файлы сторонних зависимостей. Иконки приложения из `assets/` входят в исходники проекта.
- При изменениях интерфейса сохраняйте малый расход ресурсов: анимации должны завершаться и отключаться после скрытия окна; не добавляйте постоянную перерисовку.
