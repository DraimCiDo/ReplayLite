# Проверка обновлённого интерфейса — 14 октября 2026

Сборка выполнена существующим компилятором .NET Framework без новых зависимостей. Используется WinForms и GDI+; видеозахват и параметры кодировщика сохранены.

- Проверено реальное окно: выбранные настройки, состояние записи, карточки показателей и доступность элементов.
- Короткие анимации кнопок, статуса и шкалы завершаются; постоянного таймера перерисовки нет.
- После скрытия окна число активных таймеров анимаций равно **0**.
- В отдельном двухсекундном замере скрытого интерфейса без записи приращение CPU процесса составило **0,000 с** с точностью доступного счётчика. Это короткая проверка простоя, не обещание нулевого расхода при работе.
- Значок трея проверен для состояний **выключено → запись → сохранение → ошибка → выключено**. Иконки кешируются и нативные временные HICON освобождаются.
- В живой проверке управления через новую форму буфер запущен, повтор сохранён, затем буфер остановлен. Доступность элементов окна и меню трея соответствует состоянию записи.
- Полученный в живой проверке MP4 полностью декодирован FFmpeg с кодом выхода **0**.
- Проверка интерфейса не воспроизводит тестовых сигналов и не показывает звуковых уведомлений.

Результаты полного двухминутного теста прежнего интерфейса находятся в `VALIDATION.md`. Они относятся к ядру записи; производительность анимаций во время игры и влияние обновлённого окна на игровой FPS отдельно не измерены.
