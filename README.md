## Сохраняй то, что уже произошло

Удачный момент в игре, важная демонстрация или неожиданная ошибка на экране — ReplayLite держит последние минуты в буфере. Нажми **Ctrl + Shift + F9**, и уже записанный фрагмент сохранится в MP4.

По умолчанию это **2 минуты, 30 FPS, 8 Мбит/с, звук компьютера + микрофон**. Длительность можно выбрать от **30 секунд до 10 минут**. Во время сохранения запись продолжается. После успешного сохранения использованные фрагменты удаляются из буфера, счётчик и шкала отражают только новые кадры. Следующий клип не повторяет уже сохранённые кадры; при ошибке экспорта буфер остаётся.

Вкладка **«Запись»** показывает состояние буфера, кнопку сохранения и четыре крупных показателя: CPU, память, время в буфере и место на диске. Внизу открываются папка и последний сохранённый повтор.

<p align="center">

Параметры собраны во вкладке **«Настройки»** и сохраняются автоматически. В двух равных колонках слева расположены монитор, звук, плавность и качество видео, справа — длительность и горячая клавиша. Обе вкладки используют одно окно 760×480 px при масштабе 100%; переключение не меняет его размер. Версия указана рядом с названием и в заголовке окна.

## Возможности и преимущества

| Возможность | Что это даёт |
| --- | --- |
| **Запись последних минут** | Сохраняй событие после того, как оно произошло. |
| **Аппаратное кодирование NVENC** | Видео кодируется отдельным блоком NVIDIA; CPU не выполняет программное кодирование видео. |
| **Сжатый буфер на диске** | Приложение не держит минуты несжатого видео в RAM. Старые фрагменты удаляются. |
| **MP4 без повторного кодирования** | Сохранение переносит готовые видеопотоки в итоговый файл. |
| **Звук компьютера и микрофона** | Игровой звук и голос попадают в одну стереодорожку; доступны режимы «только компьютер» и «без звука». |
| **Выбор монитора** | Реальные подключённые мониторы с моделью, разрешением и отметкой основного; список обновляется при смене экранов. |
| **Настраиваемая горячая клавиша** | Одиночная клавиша или Ctrl/Alt/Shift/Win + клавиша, включая навигацию и NumPad; проверка занятости и сохранение настройки. |
| **Portable и установка** | Один установщик предлагает оба режима; Portable хранит настройки рядом с приложением. |
| **Обновление одной кнопкой** | Скачивание из GitHub Releases, проверка SHA-256 и перезапуск с сохранением настроек и записей. |
| **Уведомления об обновлениях** | Проверка при запуске и раз в шесть часов; новая версия отмечается в окне и меню трея. |
| **Автозапуск Windows** | Программа запускается сразу в трее и автоматически включает буфер с сохранёнными настройками. По умолчанию выключен. |
| **Работа в трее** | Сохраняй повтор и управляй буфером без открытого окна. |
| **Короткие анимации** | Переходы длятся 150–200 мс и останавливаются после скрытия окна. |
| **Локальная работа** | Записи остаются на компьютере. Для работы приложения не нужны аккаунт или интернет. |

## Быстрый старт

1. Открой [последний релиз](https://github.com/DraimCiDo/ReplayLite/releases/latest) и скачай **ReplayLite-Setup.exe** или **ReplayLite-Portable.zip**.
2. В установщике выбери **обычную установку** или **Portable**. Для ZIP распакуй всю папку и запусти **ReplayLite.exe**.
3. Во вкладке **«Настройки»** выбери монитор по модели и разрешению. Перейди в **«Запись»** и нажми **«Начать запись»**.
4. Сохрани момент кнопкой **«Сохранить повтор»** или **Ctrl + Shift + F9**.

MP4 появится в выбранной папке. Поначалу сохраняется уже накопленная часть; полный двухминутный буфер доступен после двух минут записи.

> Установщик и ZIP содержат все зависимости. Обновление выполняется кнопкой **«Обновления»** в приложении. Требуются Windows 10/11 x64, .NET Framework 4.8 и NVIDIA с поддержкой NVENC. Исполняемый файл не подписан.

## Что с нагрузкой

Локальный тест ядра записи: **RTX 4060 · Ryzen 7 5700X · 2560×1440 · 30 FPS · 8 Мбит/с · буфер 120 секунд · компьютер + микрофон**.

| Показатель | Результат проверки |
| --- | --- |
| Средний CPU тестового приложения + FFmpeg | **0,53%** от всех 16 логических процессоров |
| Пиковая RAM тестового приложения + FFmpeg | **158,3 МиБ** |
| Размер кольцевого буфера с запасом | **130,4 МиБ** |
| GPU VideoEncode, четыре отдельные выборки | **5–7%** |
| Длительность полного сохранённого MP4 | **120,016 с** |

Это результаты записи рабочего стола, не игрового бенчмарка и не гарантия для другого компьютера. RAM/CPU измерены без основного окна, VideoEncode — отдельный блок GPU. Влияние на игровой FPS и общая загрузка GPU/VRAM отдельно не измерены. [Полная проверка записи](VALIDATION.md) · [Проверка нового интерфейса](UI-VALIDATION.md).

## Что учитывать

- Записывается **весь выбранный экран в исходном разрешении**, включая курсор. Захват отдельного окна/игры пока не реализован.
- **AMD и Intel не поддерживаются** этой версией. Требуется NVIDIA NVENC.
- Сохранение обычно ждёт до **2 секунд**, пока закроется текущий фрагмент. Ролик может включать до двух секунд после нажатия.
- Звук компьютера и микрофона смешивается в **одну дорожку**. Для микрофона Windows должна разрешать доступ классическим приложениям.
- При 8 Мбит/с запись пишет примерно **1 МБ/с**. Сохранённые MP4 автоматически не удаляются.
- HDR, защищённый контент и эксклюзивный полноэкранный режим отдельно не проверены.

Остальные настройки, поведение после сна и устранение ошибок — в [подробной инструкции](docs/GUIDE.md).

## Установка и обновления

С версии 0.3.3 используется тёмный мастер Inno Setup: выбор обычной установки или Portable, папки и ярлыка. Установка выполняется для текущего пользователя без прав администратора. Portable ZIP также доступен отдельно.

| Режим | Файлы программы | Настройки и записи |
| --- | --- | --- |
| **Обычная установка** | `%LOCALAPPDATA%\Programs\ReplayLite` по умолчанию; ярлык в меню «Пуск», необязательный на рабочем столе; удаление через параметры Windows | Настройки и буфер в `%LOCALAPPDATA%\ReplayLite`; MP4 по умолчанию в «Видео» |
| **Portable** | Любая выбранная папка с правом записи; доступен отдельный ZIP | Настройки и буфер в `data/`, MP4 по умолчанию в `Replays/` рядом с EXE |

Приложение проверяет последний стабильный GitHub Release при запуске и раз в шесть часов. При наличии новой версии появляется уведомление Windows, кнопка **«Обновить до…»** в окне и пункт в меню трея. Проверка занимает не более 15 секунд; ошибки сети не мешают записи. Одна версия уведомляет один раз за сеанс, а кнопка остаётся доступной. Проверку также можно запустить вручную кнопкой **«Проверить обновления»**.

Скачивание и установка начинаются только после нажатия **«Обновить до…»** в окне обновления. Проверяется SHA-256, буфер останавливается, файлы заменяются, программа перезапускается. При ошибке замены предусмотрен откат. Сохранённые MP4 и настройки не перезаписываются; несохранённый буфер при перезапуске очищается.

Переключатель **«Запускать с Windows»** находится в настройках и по умолчанию выключен. После входа в Windows программа запускается сразу в трее, без показа окна, и включает буфер с сохранёнными настройками. Если экран или звук ещё не готовы, выполняются до трёх попыток с паузой 3 секунды; окончательная ошибка отображается уведомлением и состоянием трея. Открытие окна не перезапускает запись. Работает и для Portable, если не перемещать папку. При переносе выключи автозапуск в старой копии и включи в новой.

Старая версия 0.2.x ещё не содержит кнопку обновления: установи 0.3.0 в новую папку. Обычная установка использует прежние настройки из профиля. Для переноса настроек в Portable скопируй старый `settings.txt` в `data/` перед первым запуском.

## Собрать из исходников

```powershell
git clone https://github.com/DraimCiDo/ReplayLite.git
cd ReplayLite
.\source\setup-deps.ps1
.\source\build.ps1
.\ReplayLite.exe
```

Для загрузки закреплённых зависимостей нужен интернет; SHA256 проверяется. Сборка использует компилятор .NET Framework из Windows, дополнительный .NET SDK не нужен. После сборки приложение работает без сети.

## Сборки и Releases

[GitHub Actions](https://github.com/DraimCiDo/ReplayLite/actions/workflows/build-release.yml) собирает EXE и проверяет интерфейс на Windows. Для push в `main` и pull request публикуется артефакт сборки. Push тега вида **`v0.3.2`**, совпадающего с файлом `VERSION`, дополнительно создаёт GitHub Release с **установщиком**, **Portable ZIP**, **EXE** и **SHA256SUMS.txt**.

В CI нет NVIDIA для проверки захвата: реальные проверки записи выполнены локально и описаны выше. [Как выпустить версию](docs/RELEASING.md) · [История изменений](CHANGELOG.md).
