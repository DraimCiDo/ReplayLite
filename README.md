# ReplayLite

Локальное приложение для Windows 10/11 x64 и видеокарт NVIDIA с NVENC. Эта сборка проверена на RTX 4060. Интернет, права администратора и установка не нужны. Требуется .NET Framework 4.8, обычно уже установленный в Windows 10/11.

Репозиторий содержит исходники. Для сборки после клонирования выполните в PowerShell:

```powershell
git clone https://github.com/DraimCiDo/ReplayLite.git
cd ReplayLite
.\source\setup-deps.ps1
.\source\build.ps1
.\ReplayLite.exe
```

На этапе загрузки зависимостей нужен интернет. Скрипт скачивает закреплённые версии NAudio 1.10.0 и FFmpeg 9.0.2 с проверкой SHA256, без установки в систему. После сборки приложение работает локально без сети.

## Использование

1. Распакуйте **всю** папку приложения и запустите `ReplayLite.exe`.
2. Выберите длительность, FPS, битрейт, звук и папку сохранения. По умолчанию: **2 минуты, 30 FPS, 8 Мбит/с, компьютер + микрофон**.
3. Нажмите **Включить буфер**. Запись начинается только после этого действия.
4. Нажмите **Ctrl+Shift+F9** или кнопку сохранения. Повтор появится в выбранной папке в формате MP4.
5. Закрытие окна отправляет приложение в трей. Чтобы остановить и завершить приложение, выберите **Выход** в меню значка.

Записывается весь экран в исходном разрешении, включая курсор. Индекс экрана — индекс выхода DXGI, обычно `0` для первого выхода видеокарты; порядок может отличаться от номеров в настройках Windows. Если выбранный выход недоступен, приложение выдаст ошибку. Запись отдельного окна не реализована.

## Расход ресурсов

- Захват — Desktop Duplication (`ddagrab`) с кадрами D3D11; кодирование — H.264 NVENC. Программного fallback-кодировщика нет.
- Кадры видео не передаются через управляемую память C#. Предпросмотр отсутствует. FFmpeg запускается с приоритетом `BelowNormal`.
- NVENC использует быстрый preset `p1`, без B-кадров и lookahead, с четырьмя поверхностями. Это уменьшает затраты, но при равном битрейте качество может быть ниже, чем у более медленных preset.
- Уже сжатые двухсекундные фрагменты хранятся на диске. Число фрагментов ограничено длительностью буфера плюс примерно 10 секунд запаса. Сохранение выполняет копирование потоков в MP4 без повторного кодирования.
- При настройке 8 Мбит/с запись пишет примерно 1 МБ/с. Для двухминутного буфера с запасом требуется около 130 МБ; сохранённые повторы занимают дополнительное место и автоматически не удаляются.
- Звук компьютера снимается через WASAPI loopback, микрофон — через WASAPI с устройств по умолчанию. Два входа смешиваются в одну стереодорожку AAC 48 кГц. Небольшие аудиобуферы ограничены 500 мс на вход, тишина не останавливает запись.
- CPU и RAM в окне учитывают приложение и процесс записи FFmpeg. CPU нормирован на все логические процессоры. Это не измерение потери FPS в игре.

Фактические результаты живой проверки находятся в `VALIDATION.md`. Потребление зависит от разрешения, FPS, нагрузки игры, драйверов и аудиоустройств. Приложение использует GPU для захвата и кодирования и не обещает нулевую нагрузку.

## Поведение и ограничения

- После включения доступна только уже записанная часть; полный двухминутный повтор появится после наполнения буфера.
- Сохранение ждёт закрытия текущего фрагмента, обычно до 2 секунд. Ролик включает момент нажатия и может закончиться до 2 секунд после него. Длительность округляется по границам фрагментов.
- Во время сохранения запись продолжается. Повторные нажатия блокируются до окончания экспорта.
- При аварии приложения Windows Job Object завершает дочерний FFmpeg. После штатной остановки временная папка удаляется. После аварии может остаться один ограниченный буфер в `%LOCALAPPDATA%\ReplayLite\buffer-*`; после закрытия приложения его можно удалить.
- Настройки находятся в `%LOCALAPPDATA%\ReplayLite\settings.txt`. Автозапуск не настраивается. После сна или смены аудиоустройства может потребоваться заново включить буфер.
- Лучше использовать оконный режим без рамки. Эксклюзивный полноэкранный режим, HDR, защищённый контент и игры с ограничениями захвата отдельно не проверены.
- Для микрофона Windows должна разрешать доступ классическим приложениям. Входы поддерживают моно/стерео; многоканальный вывод 5.1/7.1 нужно переключить на стерео.
- Эта версия использует NVIDIA NVENC. AMD/Intel, захват отдельной игры, выбор отдельных аудиоустройств, шумоподавление и отдельные аудиодорожки не реализованы.
- Если Ctrl+Shift+F9 занята другой программой, окно покажет сообщение; кнопка сохранения продолжит работать.
- Исполняемый файл не подписан. Сетевых функций, телеметрии и загрузки записей в облако нет.

## Исходники и сборка

Код приложения находится в `source/`. Выполните `source/build.ps1` из PowerShell. Используется существующий компилятор .NET Framework из Windows; .NET SDK для пересборки не нужен. В переносимой папке `NAudio.dll` уже включена; при клонировании Git сначала запустите `source/setup-deps.ps1`.

Тест записи: `ReplayLite.exe --self-test C:\путь\к\папке both 120`. Тест записывает экран и микрофон, проверяет сохранение, очистку кольца и декодирование роликов. Проверка не воспроизводит звуковых сигналов. Допустимые режимы звука: `both`, `system`, `none`. В тестовой папке остаются MP4 и `self-test.txt`; не используйте тест во время показа конфиденциального содержимого.

Используемые компоненты и источники: [FFmpeg Desktop Duplication](https://ffmpeg.org/ffmpeg-filters.html#ddagrab), [FFmpeg segment](https://ffmpeg.org/ffmpeg-formats.html#segment_002c-stream_005fsegment_002c-ssegment), [NAudio 1.10.0](https://github.com/naudio/NAudio/tree/v1.10.0), [WASAPI loopback](https://learn.microsoft.com/en-us/windows/win32/coreaudio/loopback-recording). Лицензии и версии см. в `THIRD-PARTY.md`.
