# Проверка ReplayLite — 14 октября 2026

Для 0.3.3 локально проверена отдельная сборка в изолированной папке: реальная установка Inno Setup в режимах Portable и обычной установки, SHA-256 каждого установленного файла относительно Portable ZIP, регистрация только для текущего пользователя, ярлык и отказ от перезаписи непустой папки. Проверки обновления подтвердили сохранность настроек/MP4, откат при заблокированном файле и перезапуск новой версии. Проверка UI прошла; реальная запись и игровой FPS для этой версии повторно не измерялись. Снятие антивирусных детектов пока не подтверждено; см. [ANTIVIRUS.md](docs/ANTIVIRUS.md).

Живая запись выполнена локально на Windows 11 (build 26300), NVIDIA GeForce RTX 4060, драйвер 617.42, AMD Ryzen 7 5700X (16 логических процессоров).

Настройки длительного теста: экран **2560×1440, 30 FPS, 8 Мбит/с**, кольцо **120 секунд**, **звук компьютера и микрофон**. Это тест рабочего стола; игра не запускалась.

| Показатель | Результат |
| --- | --- |
| Средний CPU приложения теста + FFmpeg | **0,53%** от всех логических процессоров |
| Пиковая RAM приложения теста + FFmpeg | **158,3 МиБ** working set |
| Пиковый размер кольца на диске | **130,4 МиБ** |
| Фрагментов в кольце после заполнения | **65**, плюс возможен один новый фрагмент до следующей очистки |
| Длительность полного сохранённого MP4 по ffprobe | **120,016 секунд** |
| Видеодорожка | H.264, 2560×1440, 30 FPS |
| Аудиодорожка | AAC, 48 кГц, стерео, компьютер и микрофон смешаны |
| Загрузка GPU VideoEncode в четырёх отдельных выборках | **7%, 5%, 5%, 6%** |

VideoEncode — отдельный блок GPU, а не общая загрузка видеокарты. Эти четыре выборки не заменяют измерение среднего за весь тест. RAM и CPU получены в режиме проверки ядра без основного окна; обычный интерфейс добавляет свой небольшой расход, отдельно не измеренный.

Результаты функциональных проверок:

- Двухминутное кольцо заполняется, старые фрагменты удаляются, сохранение продолжает фоновую запись.
- Начальный короткий ролик и полный двухминутный ролик декодированы FFmpeg с кодом выхода **0**, без сообщений об ошибках.
- Оба входа WASAPI дают аудиоданные. Это подтверждает работу захвата, но не является субъективной проверкой качества речи.
- Одновременное повторное сохранение отклоняется; сохранение во время остановки завершается успешно.
- Режим без звука отдельно проверен на коротком кольце: запуск, экспорт, декодирование, очистка и остановка прошли с кодом выхода **0**.
- Windows Job Object проверен отдельным тестом: приложение завершилось без штатной остановки, дочерний FFmpeg автоматически завершился.
- Итоговая сборка компилируется существующим компилятором .NET Framework с кодом выхода **0**.
- Проверено отображение реального окна и выбранных настроек. Зарегистрирована Ctrl+Shift+F9; фактическое нажатие во время игры отдельно не проверялось.
- Резкий тестовый писк удалён по просьбе пользователя. В исходниках отсутствуют `WaveOut`, `SignalGenerator`, `SystemSounds` и `SoundPlayer`; итоговые проверки не воспроизводят тестовых сигналов.
- Контрольная сумма исходного архива FFmpeg совпала с SHA256 издателя.

При записи исходное видео не проходило через `hwdownload` или программный видеокодировщик. Экспорт использует `-c copy`. Записи тестов не включены в поставку, чтобы не распространять экран и звук пользователя.

Не измерены потеря игрового FPS, полная загрузка GPU/VRAM, длительная стабильность за несколько часов, HDR, эксклюзивный полноэкранный режим и запись на других моделях GPU. Результаты не являются гарантией такого же расхода в игре.
